# Консультант 1С и база знаний ИТС

Репозиторий объединяет проверяемую базу знаний по 1С, XML-индекс локальной конфигурации и консольное приложение, которое создаёт проекты консультаций, схемы и пошаговые инструкции.

## Быстрый запуск в Windows

1. Дважды щёлкните `consultant.cmd` или выполните `./consultant.ps1` в PowerShell.
2. В меню выберите `Подключить AI` и найдите установленный Codex, Claude Code или OpenCode либо добавьте API. Подключение создаётся один раз и затем выбирается автоматически.
3. Создайте проект и укажите конфигурацию 1С. Приложение всегда использует полный
   оптимизированный процесс: обязательные вопросы, апрув требований, проект и схема,
   второй апрув, затем инструкция.
4. После результата подтвердите, всё ли устраивает, либо отправьте инструкцию на доработку.

Интерактивный режим использует короткие меню, цветные панели, таблицы, индикаторы этапов и анимацию ожидания. При перенаправлении вывода оформление автоматически отключается; переменная `NO_COLOR=1` отключает цвета вручную.

Если папка открыта непосредственно в Codex, Claude Code или OpenCode, внутреннее AI-подключение приложения не требуется: агент читает `AGENTS.md`, минимальный адаптер и общие `skills/`.

Подробно: [руководство по приложению](docs/consultant-cli.md).

## Структура

| Каталог | Назначение |
|---|---|
| `knowledge/articles/` | очищенные атомарные статьи с источниками |
| `processes/` | типовые бизнес-процессы |
| `graph/` | лёгкий граф сущностей и связей |
| `skills/` | переносимые скиллы для разных AI-агентов |
| `templates/`, `schemas/` | шаблоны и машиночитаемые контракты |
| `results/<project-id>/` | отдельные проекты и их версии |
| `examples/approved/` | индекс только явно подтверждённых инструкций |
| `metadata/index/`, `metadata/slices/` | индекс и компактные срезы XML |
| `1c_modeler_upgrade/` | графы источников, объектов, маршрутов и связей, компактный поисковый индекс и обязательная независимая проверка |
| `source/` | локальная исходная документация, исключённая из Git |
| `local/configurations/` | локальные XML-выгрузки, исключённые из Git |
| `src/consultant_cli/`, `tests/` | приложение и тесты |

## Источники и точность

XML используется только при точном совпадении продукта и релиза. Для иной конфигурации приложение отключает ERP XML, предупреждает консультанта и требует подходящую документацию и разрешённые веб-источники. В инструкции допускаются `verified`, `verified_metadata` и подтверждённый источником `inferred`; сведения без доказательств исключаются, а апрув блокируется до закрытия всех проверок.

В списке проектов отдельно отображаются состояния `В разработке`, `Не подтверждён` и
`Подтверждён`. Удаление переносит проект в `results/.trash/`; использоваться как пример
может только явно подтверждённый проект, прошедший шлюзы проверки.

Крупные source/object-графы Modeler настроены на хранение через Git LFS; компактный
поисковый индекс остаётся обычным файлом репозитория.

Инструкция не становится успешным примером автоматически. После её выдачи консультант должен явно подтвердить результат. Позднее замечание отзывает успешность, исключает инструкцию из реестра примеров и создаёт цикл доработки.

## Разработка и проверка

Требуется Python 3.11 или новее. Приложение не имеет обязательных внешних Python-зависимостей.

```powershell
$env:PYTHONPATH = "src"
py -3 -m unittest discover -s tests -v
py -3 scripts/validate_repository.py
```

Для подготовки локального XML-индекса используйте [руководство по метаданным](metadata/README.md). Перед публикацией любых материалов ИТС проверьте лицензионные права и правила доступа.

Подробнее: [архитектура](docs/architecture.md), [правила контента](docs/content-rules.md), [совместимость агентов](docs/agent-compatibility.md).
