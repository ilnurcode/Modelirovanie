# Внесение изменений

1. Создать атомарную статью по шаблону.
2. Сохранить исходный URL, продукт, релиз и дату доступа.
3. Не ставить статус verified, пока утверждения и интерфейсные шаги не проверены.
4. Связать процесс со статьями и узлами графа по стабильным идентификаторам.
5. Запустить python scripts/validate_repository.py.
6. В pull request описать источник, способ проверки и затронутые релизы.

Не коммитить закрытую исходную выгрузку, персональные данные, учетные данные или материалы без права распространения.
