# Протокол выполнения

## Полный режим

1. Сформировать только обязательные вопросы со статусом `pending_approval`.
2. После ответов и явного апрува требований сформировать проект и Mermaid-схему со
   статусом `pending_approval`.
3. После явного апрува проекта и схемы сформировать инструкцию.
4. После инструкции запросить итоговую обратную связь.

Молчание, уточнение, продолжение работы или ответ модели не являются апрувом.

## Формат результата

При вызове из приложения вернуть только JSON по переданной JSON Schema. При прямой
работе агента использовать `templates/requirements-approval.md`,
`templates/design-approval.md` и `templates/user-instruction.md` согласно стадии.

Каждый проверяемый шаг должен содержать источник и статус `verified`,
`verified_metadata` или `inferred`. Отсутствие доказательства оформлять вопросом и не
включать такой шаг в инструкцию. `inferred` разрешён в черновике, но блокирует перевод
инструкции в `successful`.
