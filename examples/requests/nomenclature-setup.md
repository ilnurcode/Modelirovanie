# Пример постановки: структура номенклатуры хлебобулочного производства

Нужно спроектировать в 1С:ERP 2.5 ведение готовой продукции, полуфабрикатов, сырья и упаковки. Для скоропортящихся позиций требуется контроль сроков годности, для муки — входной контроль качества. Производство использует рецептуры, единицы `шт` и `кг`, отдельный склад готовой продукции.

Нужно получить уточняющие вопросы, типовой вариант, схему, список объектов и настроек, инструкцию пользователю, альтернативы, ограничения и ссылки на ИТС. Точные названия интерфейсных команд нельзя считать подтверждёнными без источника.
