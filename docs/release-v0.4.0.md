# Выпуск 0.4.0

## Изменения

- В списке проектов добавлены состояния `В разработке`, `Не подтверждён` и
  `Подтверждён`, рядом сохраняется точный этап процесса.
- В меню проекта добавлено удаление с подтверждением ID. Папка переносится в
  `results/.trash/`, поэтому удаление из списка остаётся восстанавливаемым.
- Добавлена CLI-команда `delete <project-id> --confirm <project-id>`.
- После удаления автоматически перестраивается индекс успешных примеров.
- В пример допускается только проект со статусом `successful`, утверждёнными
  метаданными инструкции и событием явного апрува.

## Проверка

- автоматические тесты приложения;
- валидация репозитория;
- запуск списка проектов и команды удаления;
- автономная сборка `dist/consultant.exe` версии `0.4.0`.
