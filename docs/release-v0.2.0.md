# Выпуск 0.2.0

## Изменения интерфейса

- единая цветовая тема без внешних runtime-зависимостей;
- отдельные экраны и хлебные крошки;
- карточка состояния проекта;
- понятные русские названия статусов;
- индикаторы этапов для обоих режимов;
- таблицы проектов, источников и AI-профилей;
- пошаговый мастер создания проекта;
- анимация ожидания генерации, проверки и экспорта;
- заметные сообщения об успехе, предупреждениях и ошибках;
- паузы после действий;
- автоматический текстовый fallback и поддержка `NO_COLOR`.

## Проверки

- 11 модульных тестов UI и прежней бизнес-логики;
- интерактивный запуск в Windows Terminal;
- проверка русской кодировки;
- автономная проверка Windows-сборки.
