# 1C-Consultant 4.2.0

- Внутренний сервис обновлён из `NewAgent`: добавлен единый hybrid-результат, усилена
  нормализация источников и Vanessa-сценариев, расширена телеметрия и сохранение
  промежуточных ответов.
- Добавлена безопасная блокировка проекта с обнаружением устаревших lock-файлов.
- Сохранены исправления установленного каталога данных, графов и retry атомарной записи.
- В installer добавлена отдельная установка Pi 0.84.3 и управляемого Node.js 22.23.2.
- После установки Pi запускается из обычного ярлыка 1C-Consultant.
- Добавлены MCP compatibility-компоненты и шесть Node-тестов.
