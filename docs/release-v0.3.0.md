# Выпуск 0.3.0

## Упрощение интерфейса

- главное меню: 4 действия вместо 7;
- меню проекта: 5 действий вместо 10;
- подключение AI: 3 действия вместо 8;
- основное действие проекта меняется автоматически по текущему этапу;
- редкие функции сгруппированы в `Материалы`, `Изменить`, `Ещё` и `Система и справка`;
- пустое название проекта запрещено в меню, командах и прикладном ядре;
- редакция и релиз убраны из мастера и перенесены в необязательные дополнительные настройки;
- ручной ввод технического `AI-профиля` при создании проекта удалён;
- основное AI-подключение выбирается автоматически;
- в интерфейс добавлено объяснение назначения AI-подключения и его названия.

Редакция и релиз остаются доступными для точной маршрутизации XML. Если релиз неизвестен, приложение безопасно отключает XML как доказательство интерфейсных шагов.
