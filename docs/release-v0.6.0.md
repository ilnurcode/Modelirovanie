# Выпуск 0.6.0

- Installer без параметров предлагает manifest последнего GitHub Release.
- Enter при выборе графов устанавливает все доступные графы.
- Launcher передаёт приложению `CONSULTANT_DATA_DIR`.
- Modeler читает активный внешний граф из `config/installed.json`.
- Windows-приложение собирается из исходников в GitHub Actions.
- Граф версии 0.5.0 публикуется отдельно и не дублируется в архиве приложения.
