# Выпуск 0.7.0

- Installer открывает интерактивное меню без обязательных аргументов.
- Источник пакетов выбирается понятными пунктами: интернет или offline bundle.
- Приложение нативно собирается для Windows x64, Linux x64/ARM64 и macOS x64/ARM64.
- GitHub Actions объединяет пять application-пакетов и пять Go-installer’ов в один Release.
- Manifest автоматически направляет installer на пакет его ОС и архитектуры.
