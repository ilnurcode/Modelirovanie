# NewAgent 4.1.3

- Installer сохраняется в каталоге установки и обновляется из release manifest.
- Ярлык предлагает запуск сервиса или повторное управление установкой и графами.
- Графы выбираются по номерам; технический ID вводить не требуется.
- Поддержаны установка/обновление, откат и удаление всех версий выбранного графа.
- Состояние хранит активную, предыдущую и все установленные версии графа.
