# XML метаданных 1С

Локальные выгрузки хранятся в `local/configurations/<configuration-id>/` и исключены из Git. Текущая ERP-выгрузка находится в `local/configurations/erp-2.5.27.49/`.

Поддерживаются выгрузка Конфигуратора «Конфигурация → Выгрузить конфигурацию в файлы» и исходники 1C:EDT. Перед импортом зафиксируйте продукт, релиз, наличие расширений и дату выгрузки.

Полный индекс строится так:

```powershell
py -3 scripts/index_1c_config.py local/configurations/erp-2.5.27.49 --output metadata/index
```

Индекс запрашивается через `query_1c_metadata.py`, `inspect_1c_ui.py` и `trace_1c_command.py`; весь `objects.ndjson` нельзя загружать в контекст агента. В Git сохраняются только `configuration.json`, компактные срезы `metadata/slices/` и связи графа без исходного кода модулей.

XML можно считать доказательством только при точном совпадении конфигурации и релиза проекта. Пользовательский путь интерфейса дополнительно подтверждается формой, командой или проверкой в целевой базе.
