# Переносимый комплект «Консультант 1С»

Эту папку можно скопировать на другой компьютер целиком. Она содержит код
приложения, общие Skills, шаблоны, схемы, нормализованные знания и производный
пакет графов 1С:ERP 2.5.27.49.

## Что намеренно не включено

- XML-выгрузка конфигурации из `local/`;
- исходная документация ИТС из `source/`;
- входные DOCX, PDF и XLSX;
- рабочие проекты из `results/`;
- оценочный комплект из `тест/`;
- временные файлы, сборки, кэши и виртуальное окружение;
- `consultant.local.toml`, API-ключи и другие локальные настройки;
- материалы процесса хлебозавода и иные пользовательские входные данные.

## Требования к компьютеру

1. Windows 10/11.
2. Для обычной работы Python не требуется: используйте `consultant.exe`.
3. Python 3.11 или новее нужен только для запуска исходного кода и тестов.
4. Для AI — один из вариантов:
   - Codex, OpenCode или Claude Code, если папка открывается непосредственно в агенте;
   - AI API, подключаемый через меню приложения.

## Проверка и запуск

1. Распакуйте или скопируйте папку в каталог, доступный на запись.
2. Запустите `CHECK_INSTALL.cmd`.
3. Если проверка успешна, запустите `START.cmd` или `consultant.exe`.
4. В меню подключите AI или откройте эту папку непосредственно через Codex/OpenCode.

Приложение создаёт новые проекты в `results/<project-id>/` уже на компьютере
получателя. Локальные AI-профили записываются в новый `consultant.local.toml` и
не входят в исходный комплект.

## Ограничение Modeler без XML

В комплект включены производные route graph, semantic graph и поисковый индекс,
но не первичный XML. Они позволяют искать объекты, маршруты и связи как
кандидаты. Строгий статус `verified_metadata`, требующий доступного первичного
XML точного релиза, на другом компьютере не должен присваиваться автоматически.
Такие проверки остаются `inferred`/`unresolved` и блокируют финальный апрув до
проверки в целевой базе или подключения подписанного доказательного пакета.

## Состав

Полный список файлов и контрольные суммы находятся в `FILES.sha256`.
Машиночитаемое описание комплекта находится в `PACKAGE_MANIFEST.json`.

`consultant.cmd` и `consultant.ps1` оставлены для разработчиков и требуют Python.
